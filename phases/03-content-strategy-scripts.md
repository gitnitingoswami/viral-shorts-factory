# Phase 03 — AI Content Strategy and Scripts

Turn approved trend topics into original content proposals.

## Features
- Generate five distinct content ideas per approved topic.
- Include target audience, angle, hook, value proposition, duration, format, and source references.
- Generate original 20–60 second scripts and scene-by-scene storyboards.
- Each scene includes narration, visual concept, on-screen text, duration, transition, and asset-generation brief.
- Fact-check factual claims against supplied sources; flag unsupported claims.
- Evaluate originality, repetition, clarity, pacing, accessibility, platform suitability, and rights/policy risks.
- Version scripts and retain review history.
- Angular idea list, script editor, storyboard view, review and approval UI.

## Suggested entities
ContentIdea, ContentStrategy, VideoScript, ScriptVersion, Storyboard, StoryboardScene, ScriptReview.

## Acceptance
Scripts are traceable to inputs; unsupported claims are flagged; versions are preserved; review state is explicit; tests cover prompt failures, malformed outputs, and duplicate ideas.
